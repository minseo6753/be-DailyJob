# be-DailyJob 

> 이 회고는 작업량을 보고하기 위한 문서가 아니라, 
> 오늘 내가 어떤 판단을 했고 어떤 개발 행동을 반복하거나 바꿔야 하는지 확인하기 위한 기록입니다. 
> 각 항목은 길게 쓰기보다, 사실/판단/근거/다음 행동이 드러나게 구체적으로 작성하세요.

### 1. 오늘 완료한 것
- 오늘 실제로 끝낸 기능/수정/학습: 데모 구경, 스쿼드 세션, 배송 상태 전이 알림 관련 논의, 라이더 실시간 위치 처리 관련 공부
- (오늘의 목표 중에서) 아직 끝내지 못한 부분: 코드 리뷰

### 2. 오늘 가장 의미있었던 기술적 판단
- 내가 내린 판단: 배송 상태 전이 알림을 폴링없이 SSE로 하자
- 그렇게 판단한 이유: 로직의 단순화
- 고려했지만 선택하지 않은 대안: 상태 전이 이벤트 시에만 SSE로 보내고 폴링으로 보완
- 이 판단이 코드 품질/테스트/유지보수에 미친 영향: 아직 확정되지 않음

### 3. 가장 막혔던 문제와 해결 과정
- 문제 상황 또는 증상:
- 처음 추측한 원인:
- 원인을 확인하기 위해 시도한 방법:
- 실제 원인:
- 해결 방법:
- 다음에 비슷한 문제가 생기면 먼저 확인할 것:

### 4. 오늘 잘한 행동(개발과 관련된 것)
- 어떤 행동이었는지: 모르는 내용은 바로 물어보기
- 그 접근이 도움이 된 이유: 지식을 얻음
- 다음에도 반복하고 싶은 점: 모르면 물어보기

### 5. 오늘 아쉬웠던 행동(개발과 관련된 것)
- 비효율적이었던 접근/놓치거나 부족했던 점: 공부를 좀 더 체계적으로 하고 기록을 잘 하면 좋을 것 같다.
- 그렇게 된 원인: 귀찮음, 시간없음
- 다음에는 다르게 해볼 구체적인 행동: 공부 내용 기록하기
