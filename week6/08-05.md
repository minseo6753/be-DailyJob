# be-DailyJob 

> 이 회고는 작업량을 보고하기 위한 문서가 아니라, 
> 오늘 내가 어떤 판단을 했고 어떤 개발 행동을 반복하거나 바꿔야 하는지 확인하기 위한 기록입니다. 
> 각 항목은 길게 쓰기보다, 사실/판단/근거/다음 행동이 드러나게 구체적으로 작성하세요.

### 2. 오늘 가장 의미있었던 기술적 판단
- 내가 내린 판단: 기존의 프론트엔드 코드를 변경함
- 그렇게 판단한 이유: 화면이 분리되었는데 반영이 안되어 있었음 
- 고려했지만 선택하지 않은 대안: 기존 코드 유지
- 이 판단이 코드 품질/테스트/유지보수에 미친 영향: 버리는 데이터가 없어짐

### 3. 가장 막혔던 문제와 해결 과정
- 문제 상황 또는 증상: SQL이 실행되지 않음
- 처음 추측한 원인: 쿼리의 문제
- 원인을 확인하기 위해 시도한 방법: 데이터베이스 재연결, 팀원과 논의
- 실제 원인: IDE의 경고
- 해결 방법: 무시하고 실행
- 다음에 비슷한 문제가 생기면 먼저 확인할 것: 알림

### 4. 오늘 잘한 행동(개발과 관련된 것)
- 어떤 행동이었는지: 재택근무 가능일이지만 출근함
- 그 접근이 도움이 된 이유: 동료들과 원활하게 소통할 수 있었음
- 다음에도 반복하고 싶은 점: 출근하기

### 5. 오늘 아쉬웠던 행동(개발과 관련된 것)
- 비효율적이었던 접근/놓치거나 부족했던 점: 수업에 집중하지 못함
- 그렇게 된 원인: 수면부족
- 다음에는 다르게 해볼 구체적인 행동: 7시간이상 자기
