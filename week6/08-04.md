### 2. 오늘 가장 의미있었던 기술적 판단

- 그렇게 판단한 이유: AI 사람이 놓치기 쉬운 부분까지 꼼꼼하게 잘 잡아낸다

### 3. 가장 막혔던 문제와 해결 과정
- 문제 상황 또는 증상: 라이더 세션 만료 처리의 구현 방법이 너무 복잡하다
- 처음 추측한 원인: 로직 자체의 복잡성
- 원인을 확인하기 위해 시도한 방법: 연관 코드 리뷰, 관련 정보 공부(redis)
- 실제 원인: 사실 처리할 필요 없었다.
- 해결 방법: 배차 위치 검색 방향을 라이더 기준으로 결정하고 redis 저장소에서 AVAILABLE 라이더의 위치를 제거함. 이에 관련된 결정 사항들을 문서로 정리함
- 다음에 비슷한 문제가 생기면 먼저 확인할 것: 관련 코드 구현 사항
