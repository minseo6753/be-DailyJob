# be-DailyJob 

> 이 회고는 작업량을 보고하기 위한 문서가 아니라, 
> 오늘 내가 어떤 판단을 했고 어떤 개발 행동을 반복하거나 바꿔야 하는지 확인하기 위한 기록입니다. 
> 각 항목은 길게 쓰기보다, 사실/판단/근거/다음 행동이 드러나게 구체적으로 작성하세요.

### 1. 오늘 완료한 것
- 오늘 실제로 끝낸 기능/수정/학습: Github Projects 정리, 엔티티 구현
- (오늘의 목표 중에서) 아직 끝내지 못한 부분: AWS SSM 설정 -> 포기

### 2. 오늘 가장 의미있었던 기술적 판단
- 내가 내린 판단: Github Projects에 스프린트 뷰를 추가하고, 이슈의 속성을 정리했다.
- 그렇게 판단한 이유: 칸반보드로 프로젝트를 효율적으로 관리하기 위함
- 고려했지만 선택하지 않은 대안: 스프린트별로 프로젝트 생성하기
- 이 판단이 코드 품질/테스트/유지보수에 미친 영향: 이슈를 한눈에 보고 관리하기 수월해졌다.

### 3. 가장 막혔던 문제와 해결 과정
- 문제 상황 또는 증상: EC2 역할 변경이 안 됨
- 처음 추측한 원인: AWS 상의 연결 문제
- 원인을 확인하기 위해 시도한 방법: AWS CLI를 설치해 사용해보려 했으나 과하다고 판단
- 실제 원인: 불명
- 해결 방법: 기존에 있던 역할을 먼저 해체한 후에 설정
- 다음에 비슷한 문제가 생기면 먼저 확인할 것: AWS CLI?

### 4. 오늘 잘한 행동(개발과 관련된 것)
- 어떤 행동이었는지: 동료의 pr을 보고 내 코드와의 충돌 가능성을 사전에 파악해 고친 것
- 그 접근이 도움이 된 이유: 코드 충돌없이 원활하게 merge할 수 있었다.
- 다음에도 반복하고 싶은 점: 코드 리뷰 잘하기

### 5. 오늘 아쉬웠던 행동(개발과 관련된 것)
- 비효율적이었던 접근/놓치거나 부족했던 점: AI가 생성한 코드의 리뷰를 거의 하지 않았다.
- 그렇게 된 원인: 집중력 저하
- 다음에는 다르게 해볼 구체적인 행동: 생성된 코드를 모두 이해할 수 있을 떄 커밋하기
